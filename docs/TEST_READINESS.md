## 0. 테스트 전에 꼭 해야 하는 공통 준비 (코드 수정 아님)

1. **Google 로그인 테스트 사용자 등록**
   - Google Cloud의 OAuth 앱이 "테스트 모드"예요. 참가자 Google 계정을 **테스트 사용자 목록에 미리 추가**하지 않으면 로그인 자체가 막혀요.
   - Drive 읽기 권한(`drive.readonly`)을 쓰기 때문에 참가자에게 **"Google에서 확인하지 않은 앱"** 경고가 떠요. 진행자가 "고급 → 이동"을 안내할지, 이 경고 자체를 테스트 관찰 대상으로 볼지 정해야 해요.
2. **Drive 폴더 공유**
   - 캐릭터 폴더는 공유 문서함의 `afterlife_my data` 안에서만 고를 수 있어요. 참가자 계정에 **`afterlife_my data` 폴더를 공유**해 두지 않으면 "폴더를 찾을 수 없어요"가 떠요.
3. **계정 전략 정하기** (추천)
   - Task 2·7(가입·연동·인물 추가)은 **참가자 본인 계정**으로.
   - Task 3~6(탐색·리캡·안전장치)은 **미리 캐릭터·책장·섹션을 채워 둔 진행자 계정**으로 바꿔서 진행.
   - 참가자 새 계정은 캐릭터·책·섹션이 모두 비어 있어서 Task 3~6을 할 수 없어요.
4. **Drive 연결 7일 만료**
   - 테스트 모드에서는 Drive 연결이 약 7일 뒤 끊겨요. 진행자 계정은 **테스트 전날 다시 연결**해 두세요. 끊기면 캐릭터에 "Drive 연결 끊김"이 뜨고 사진이 안 나와요. 캐릭터를 우클릭하면 다시 연결할 수 있어요.

### Quick Exit, 블러, 노출 강도는 어디에? (추가 확인 항목 답)
- **Quick Exit:** 책장·책·리캡의 오른쪽 위 "✕ 중단하기 Esc" 버튼 + Esc 키. 글을 적는 중이거나 설정 창이 떠 있으면 Esc는 그쪽에 먼저 쓰여요.
- **블러:** 리캡의 모든 사진과 책 화면의 섹션 대표 사진(대표 사진은 절반 세기). 눌러서 본 사진은 계속 선명해요.
- **노출 강도:** 리캡 왼쪽 위 👁 조절(5단계), 설정의 인물 편집과 캐릭터 만들기 4단계의 "고인을 떠올릴 때 마음" 슬라이더. 셋 다 같은 값(캐릭터별)이에요.

### 막힐 수 있는 지점
