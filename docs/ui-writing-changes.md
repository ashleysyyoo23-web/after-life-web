# After Life UI 문구 변경 목록

출처: After Life UI 라이팅 가이드 (2026-11-02, 서은솔)
규칙과 용어 사전은 `.cursor/rules/ui-writing.mdc`를 따른다.

- 화면에 보이는 글자만 바꾼다. 변수 이름, 주소, 저장 값은 바꾸지 않는다.
- ⚙️ 표시는 문구만으로 끝나지 않고 기능(버튼 추가, 동작 확인 등)이 함께 필요한 항목이다. 바꾸기 전에 지금 기능이 문구대로 동작하는지 먼저 확인하고 알려 준다.
- `{이름}`이 들어간 문구는 조사를 받침에 맞게 자동 처리한다.
- 다 바꾼 항목은 `[ ]`를 `[x]`로 표시한다.

## 1. 로그인

| | 지금 문구 | 바꿀 문구 | 메모 |
|---|---|---|---|
| [x] | 위 버튼으로 내 Google 계정에 로그인해요. 이때 내 Google Drive도 함께 연결돼요. | 위 버튼으로 Google 계정에 로그인해요. 사진을 가져올 수 있도록 Google Drive도 함께 연결돼요. | Drive를 왜 연결하는지 먼저 알려 준다 |
| [x] | 마이 랜드 오른쪽 위 + 고인 불러오기로 기억하고 싶은 사람을 추가해요. | 나의 섬 오른쪽 위의 ‘+ 그리운 분 추가하기’를 눌러요. | 버튼 이름을 화면과 똑같이 |
| [x] | 그 사람의 사진이 담긴 폴더를 내 Google Drive에서 골라요. 그 사진으로 리캡이 만들어져요. | 그분의 사진이 담긴 Drive 폴더를 고르면, 그 사진들을 날짜순으로 엮어 추억 모음을 만들어 드려요. | ‘리캡’이 처음 나오는 자리라 풀어 준다 |

## 2. 섬지기 안내 (6단계, MapTutorial)

| | 지금 문구 | 바꿀 문구 | 메모 |
|---|---|---|---|
| [x] | AFTER LIFE는 그리운 사람을 천천히 기억하는 섬들이에요. 섬들을 짧게 소개해 드릴게요. | AFTER LIFE는 그리운 분을 천천히 기억할 수 있는 섬들이 모인 바다예요. 네 개의 섬을 짧게 안내해 드릴게요. | 섬이 몇 개인지 알려 준다 |
| [x] | 가운데 섬은 마이 랜드예요. 내가 불러온 사람들이 모여 있어요. | 가운데는 나의 섬이에요. 내가 추가한 그리운 분들이 이곳에 머물러요. 캐릭터를 누르면 그분의 방과 기록 책장이 열려요. | ‘섬은 랜드예요’ 같은 겹치는 이름 없애기 |
| [x] | 아래쪽 두 섬은 개인 추모 랜드예요. (…) 기일이 다가오면 이 자리에 떠올라요. | 아래쪽 두 섬은 추모의 섬이에요. 한 분을 함께 기억하는 가족과 지인이 꽃과 메시지를 남기는 곳으로, 기일이 가까워지면 바다 위로 떠올라요. | ‘이 자리’를 장면으로 구체화 |
| [x] | 오른쪽 위 섬은 저장소예요. 마음에 담아 둔 리캡과 메시지를 언제든 다시 꺼내 볼 수 있어요. | 오른쪽 위는 추억 보관함이에요. 추억 모음이나 메시지를 북마크해 두면 이곳에 모여요. | 실제 행동(북마크)을 알려 준다 |
| [x] | 길을 잃으면 위쪽 메뉴를 찾아 주세요. 설정에서 기록을 마주하는 속도와 방식을 … | 어디로 가야 할지 막막할 때는 화면 위 메뉴에서 섬을 골라 바로 갈 수 있어요. 설정에서는 추억을 마주하는 속도와 방식을 내 마음에 맞게 바꿀 수 있어요. | 메뉴로 무엇을 할 수 있는지 구체적으로 (위쪽 메뉴에 섬 목록이 없어서 ‘AFTER LIFE 글자를 눌러 지도로 돌아오기’로 바꿔 씀) |

| | 지금 문구 | 바꿀 문구 | 메모 |
|---|---|---|---|
| [x] ⚙️ | 아직 섬에 아무도 없어요. 로그인하면 기억하고 싶은 분을 불러올 수 있어요. | 아직 섬이 비어 있어요. 로그인하고 그리운 분을 추가하면 이곳에서 다시 만날 수 있어요. (버튼: 로그인하고 시작하기) | 빈 화면에 누를 수 있는 버튼 추가 필요 |
| [x] | + 고인 불러오기 | + 그리운 분 추가하기 | 용어 사전 기준 |
| [x] | 감정 기록 돌아보기 | 마음 일기 돌아보기 | |
| [x] ⚙️ | 오늘의 마음은 어떤 날씨 같나요? / 저장하기 | 질문은 그대로 / 버튼: 오늘 마음 남기기, 보조 버튼: 오늘은 건너뛸게요 | ×만 있으면 건너뛰어도 되는지 모름. 보조 버튼 추가 필요 |
| [x] | ‘나중에’를 고르면 이번 기간 동안 다시 묻지 않아요. 지도 아래에서 언제든 열 수 있어요. | ‘나중에’를 고르면 이번 기일이 지날 때까지 다시 묻지 않을게요. 지도 아래 ‘섬 열기’에서 언제든 열 수 있어요. | 기준을 분명히 |

## 4. 그리운 분 추가 · 설정

| | 지금 문구 | 바꿀 문구 | 메모 |
|---|---|---|---|
| [x] | 호칭을 적어 주세요. | 평소 어떻게 부르셨는지 적어 주세요. | 서류 같은 말 대신 대화체 |
| [x] | {이름}를 떠올릴 때 마음이 어떠신가요? | {이름}{을/를} 떠올리면 지금 마음이 어떤가요? | 조사 자동 처리 |
| [x] | 슬픔이 파도처럼 밀려와요 / 감정이 잔잔해요 | 아직 슬픔이 파도처럼 밀려와요 / 이제는 마음이 조금 잔잔해요 | 어느 쪽을 골라도 괜찮게 |
| [x] | 왼쪽일수록 기록 사진을 더 흐리게 보여 드려요. 리캡을 보는 중에도 바꿀 수 있어요. | 왼쪽으로 옮길수록 사진이 더 흐릿하게 보여요. 추억 모음을 보는 중에도 바꿀 수 있어요. | 조작과 결과를 한 문장에 |
| [x] | {이름}와 관련해서 보고싶지 않은 기록이 있나요? 선택하신 기록은 언제든 바꿀 수 있어요. | {이름}{과/와}의 추억 중에 아직 보고 싶지 않은 것이 있다면 골라 주세요. 고른 것은 가려 두고, 언제든 다시 바꿀 수 있어요. | 조사 자동 처리, 띄어쓰기 |
| [x] | 위의 날짜가 다가오면 적절한 기록을 열람하시도록 추천해도 될까요? | 위 날짜가 다가오면 그날에 어울리는 추억을 먼저 꺼내 보여 드려도 될까요? | 행정 말투 덜어내기 |
| [x] | 남길 기록으로 보여줄 나의 사진을 골라 주세요. 사진을 눌러 포함/제외할 수 있어요. | 추억 모음에 넣을 내 사진을 골라 주세요. 사진을 한 번 누르면 넣고, 다시 누르면 빼요. | ‘포함/제외’를 실제 조작으로 |
| [ ] ⚙️ | Drive 연결 끊김 · 우클릭 | Drive 연결이 끊겼어요 (바로 옆에 ‘다시 연결하기’ 버튼) | 우클릭 대신 보이는 버튼 필요 |
| [x] | 인물에게 계정을 이어 주지 못했어요. | 이 Drive 계정을 연결하지 못했어요. 잠시 뒤 다시 시도해 주세요. | |
| [x] | 사진 N장으로 섹션 추가하기 | 고른 사진 N장으로 묶음 만들기 | ‘섹션’ → ‘묶음’ |
| [x] ⚙️ | 분류를 마쳤어요. N장은 분류하지 못했어요. | 분류를 마쳤어요. 나머지 N장은 ‘아직 분류 안 됨’에서 직접 골라 주세요. | ‘아직 분류 안 됨’ 칩 이름이 화면과 같은지 확인 (같음. ‘다시 눌러 분류’ 안내도 남김) |

## 8. 용어 일괄 정리 (위 표에 없는 나머지 화면)

위 목록을 다 바꾼 뒤, 프로젝트 전체에서 화면에 보이는 글자 중 용어 사전의 ‘쓰지 않는 말’이 남아 있는지 찾아 바꾼다.
예: ‘고인 관련 설정’ → ‘그리운 분 설정’, ‘개인 추모 랜드’ → ‘추모의 섬’, ‘커뮤니티 추모 랜드’ → ‘함께 기억하는 섬’, ‘저장소’ → ‘추억 보관함’, 화살표 기호 → ‘다음 ›’ / ‘‹ 이전’
